# 🛒 دكّاني — Dokkani

تطبيق توصيل بقالة احترافي لمدينة رام الله، فلسطين 🇵🇸

## المميزات
- 🏪 26 قسم رئيسي مع أقسام فرعية
- 📦 إدارة المنتجات والأقسام من لوحة التحكم
- 🔔 تنبيهات تيليجرام فورية للطلبات الجديدة
- 💳 دعم الدفع: كاش + Reflect QR
- 📱 تصميم متجاوب لجميع الشاشات
- 🗺️ دعم تحديد الموقع GPS
- 👥 نظام إدارة الزبائن و VIP
- 💰 نظام محاسبة وتتبع الأرباح

## التقنيات المستخدمة
- **Backend:** Python 3.11 + Flask
- **Database:** SQLite
- **Frontend:** HTML + CSS + Vanilla JS
- **Deployment:** Render
- **Notifications:** Telegram Bot API

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
